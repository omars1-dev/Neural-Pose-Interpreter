# 🤖 Neural Camera-Pose Translation
### **Learning 3D Geometric Perspectives of Humanoid Structures via Conditioned U-Net**

---

## 🌟 نظرة عامة عن المشروع (Project Overview)
هذا المشروع عبارة عن نظام متطور يعتمد على **الرسم العصبي (Neural Rendering)** و**الاستدلال المكاني (Spatial Reasoning)**. يهدف النظام إلى تمكين الذكاء الاصطناعي من "تخيل" واستنتاج المنظور الهندسي للأجسام ثلاثية الأبعاد المعقدة (Humanoid) من زوايا رؤية جديدة تماماً (Novel View Synthesis)، بناءً على **صورة مصدر واحدة فقط** (One-Shot Learning) ومتجه يحدد تموضع الكاميرا المستهدفة ($Yaw$ & $Pitch$).

---

## 🧠 الفلسفة الجوهرية وآلية العمل (Philosophy & Mechanism)
يعمل النموذج كـ **"مُترجم مكاني وعصبي"** يسد الفجوة بين البُعد الثنائي والثلاثي:
1. **تفكيك الصورة (Encoding):** يقوم بتحليل الصورة المصدر واستخلاص الميزات الدلالية والهندسية للجسم.
2. **حقن الوضعية (Pose Conditioning):** يتم دمج إحداثيات الكاميرا المطلوبة في أضيق نقطة بالشبكة (Bottleneck) لتوجيه عملية الرسم.
3. **إعادة البناء (Decoding):** يقوم النموذج بتوليد المنظور الجديد بكسل ببكسل، محاكياً اختفاء الأطراف وتداخلها هندسياً عند الدوران (**Geometric Occlusion**).

---

## 🛠️ المعمارية التقنية والخوارزميات (Technical Architecture)
* **معمارية النموذج:** شبكة **Conditioned U-Net** معززة بـ **روابط تخطي (Skip Connections)** لنقل تفاصيل الحواف الحادة مباشرة ومنع ضبابية الصور الناتجة.
* **محرك البيانات (Procedural Data Engine):** تم بناء محرك رندر داخلي يعتمد على **إسقاط المنظور الرياضي (Perspective Projection)** لتوليد مجسمات بشرية هندسية بدقة $128 \times 128$ بكسل.
* **دالة التحسين (Optimizer):** خوارزمية **AdamW** بمعدل تعلم $1e-3$ لضمان استقرار الأوزان.
* **دالة الخسارة (Loss Function):** الاعتماد على **L1 Loss (MAE)** للحفاظ على حدة البكسلات والتباين الهيكلي.

---

## 📊 النتائج والتحليل الإحصائي (Performance & Results)
حقق النموذج كفاءة استثنائية أثبتت فهمه للقواعد الهندسية وليس مجرد حفظ البيانات:
* **معدل الخطأ النهائي (Validation Loss):** وصل إلى قيمة قياسية تبلغ **$0.0043$**.
* **زمن الاستجابة (Inference Time):** توليد أي زاوية رؤية جديدة في أقل من **0.1 ثانية**.
* **الاستضافة السحابية:** تم رفع ملف الأوزان بنجاح على منصة **Hugging Face Hub** لضمان استدعاء سحابي ديناميكي.

## 🚀 التشغيل والاستخدام (Getting Started)

### 1. تثبيت البيئة والمكتبات
للبدء، قم بتثبيت المتطلبات البرمجية اللازمة عبر الأمر التالي:

```bash
pip install -r requirements.txt
```

 ## 2. تشغيل التطبيق والتفاعل مع الواجهة:
عند تشغيل الملف الرئيسي، سيقوم النظام تلقائياً بسحب ملف الأوزان الحقيقي humanoid_unet_v1.pth من مستودعنا السحابي على Hugging Face (Omarrs11/Humanoid-model):

```Bash
python app.py

```

بمجرد التشغيل، سيظهر لك في الطرفية رابط (Public URL). عند فتحه، ستظهر لك واجهة Gradio التفاعلية، حيث يمكنك تحريك مؤشرات الـ (Sliders) لتغيير زوايا الكاميرا ورؤية التوقعات الهندسية فوراً.
